# Sillon — presse à vinyles

Jeu mobile (web) : grave la musique, fabrique la galette (uni, points ou liquide), presse-la à la presse hydraulique, ébavure, colle l'étiquette et écoute ton disque. Niveaux infinis, chaque commande a son propre morceau généré.

Jouer : https://sucrayyyy.github.io/sillon/ — sur iPhone, Safari → Partager → « Sur l'écran d'accueil ».

100 % HTML/JS, sons synthétisés en direct (Web Audio), aucune dépendance.
